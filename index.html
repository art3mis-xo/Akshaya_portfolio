F1 Analytics & AI 01

PitWall Intelligence — F1 Race Analytics & AI Platform

An end-to-end Formula 1 analytics platform combining race prediction, telemetry exploration, and grounded AI analysis. Built around FastF1 data, an XGBoost finishing-position predictor, SHAP explanations, and a LangGraph-powered AI race analyst.

1 Predicts driver finishing positions using engineered race, qualifying, weather, circuit, teammate, tyre-strategy, and grid-penalty features
2 Provides SHAP-based explanations for individual predictions, letting users inspect which features influenced a driver's predicted result
3 Interactive telemetry workspace for comparing position changes, tyre strategy, gear shifts, lap times, and multi-driver speed traces with circuit corner annotations
4 LangGraph + Groq AI analyst with typed tools for predictions, model explanations, historical driver statistics, live race data, and current F1 news
FastF1 XGBoost SHAP LangGraph Groq FastAPI React TypeScript Vite Plotly Pandas

Multi-Agent AI / Product 02

StudyAI — Agentic Personalized Learning System

A multi-agent tutoring system built with LangGraph, featuring a router and specialist nodes for teaching, quiz generation, and evaluation, plus a profiler node that adapts to the learner's history. Backed by a session- and user-scoped RAG pipeline supporting 7 file formats with isolated retrieval per user/session.

1 Improved response accuracy by 30% over a single-agent baseline
2 RAG pipeline supporting PDF, DOCX, PPTX, CSV, XLSX, JSON, & TXT with Camelot table extraction
3 Dual vector-store architecture (ChromaDB / Pinecone) with strict user/session isolation
4 Full-stack with FastAPI, JWT auth, streaming chat & React/Vite on Groq Llama 3.3
LangGraph FastAPI React Vite ChromaDB Pinecone FastEmbed JWT Groq / Llama 3.3

Financial AI System 03

MCP-Quant Financial Research — Provenance-Aware AI Research System

A financial research system built around the Model Context Protocol (MCP), designed to keep LLM reasoning separate from deterministic data retrieval, validation, and quantitative analysis. The system emphasizes safe tool use, provenance, reproducibility, and reliable AI-generated research.

1 MCP server exposing typed tools for market-data retrieval, risk analysis, and end-to-end financial research workflows
2 Deterministic Python analytics for returns, volatility, Sharpe ratio, drawdown, and beta — keeping quantitative calculations outside the LLM
3 Pydantic-validated tool contracts with data-quality checks and provenance metadata including source, retrieval time, requested range, and validation status
4 Narrow LLM boundary where the model handles optional planning and narrative synthesis while execution remains controlled, reproducible, and auditable
MCP Python Pydantic Pandas NumPy Yahoo Finance LLM Tool Calling Pytest

Spatial-Temporal ML 04

Singapore Housing Market Prediction — Spatial-Temporal ML for HDB Resale Prices

A machine learning system for predicting Singapore HDB resale prices, built around a large transaction dataset enriched with spatial, temporal, and economic features. The project focused not just on fitting a model, but on understanding which representations and model families work best for complex tabular housing data.

1 Built a preprocessing and feature-engineering pipeline over 160K+ resale transactions, combining flat attributes with geospatial and economic information.
2 Engineered walking-distance features to nearby MRT stations, schools, malls, and hawker centres, alongside cyclical time features, RPI trends, localized rental indicators, and target-encoded location features.
3 Systematically compared linear models, KNN, MLPs, Random Forest, Gradient Boosting, and HistGradientBoosting, testing alternative target formulations including raw price and price-per-square-metre representations.
4 Used SHAP to inspect model behaviour and feature interactions, making the predictions more interpretable and analysing how size, remaining lease, location, and temporal factors contributed to valuation.
Python Pandas Scikit-learn GeoPandas SHAP NumPy Jupyter
View Project on GitHub
Published Research 05
📄 Published by IGI Global

Attention-Driven CNN–ViT Feature Fusion for Brain Tumor Classification

A hybrid deep-learning architecture combining DenseNet-201, Vision Transformers, and cross-attention fusion for multi-scale brain tumor classification from multimodal MRI scans, published by IGI Global.

1 Extracted fine, medium & coarse-grained MRI features using DenseNet-201
2 Designed cross-attention fusion mechanism combining multi-scale representations
3 Evaluated on BraTS 2015 dataset across T1, T1ce, T2, and FLAIR modalities
4 Achieved ~97% classification accuracy, outperforming standalone DenseNet-201 (~86%) & ViT (~93%)
TensorFlow / Keras DenseNet-201 Vision Transformers Self-Attention Cross-Attention
